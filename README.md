# BAYES-GUARD Advisory, LLC — Corporate Information Site

Single-page corporate-information site for BAYES-GUARD Advisory, LLC.
Hosted on GitHub Pages at https://bayesguard-advisory.com.

## Files

- `index.html` — the entire site (single file, no build step, no dependencies)
- `CNAME` — tells GitHub Pages to serve the site at bayesguard-advisory.com

## Editing

Open `index.html` in any editor. After the LLC is filed, update these placeholders
in the Corporate Record section:

- `Pending — 2026` → actual formation date (e.g., `[Month] [Day], 2026`)
- `Pending Issuance` (Control Number) → the Georgia SOS Control Number
- `Pending IRS Assignment` (EIN) → the issued EIN (or leave masked as `XX-XXXXXXX`)
- Update the `<title>` and meta tags if desired
